Work in Parallel

Awaiting on the line that starts the work is the most common performance bug in async code, and it's invisible — the code is correct, just slower than it needs to be.

The waterfall

// three round trips, one after another
const user = await fetch("/api/user").then((res) => res.json());
const config = await fetch("/api/config").then((res) => res.json());
const flags = await fetch("/api/flags").then((res) => res.json());

None of these depend on each other, but the second request doesn't start until the first has come back. Total time is the sum.

Start first, await later

const [user, config, flags] = await Promise.all([
  fetch("/api/user").then((res) => res.json()),
  fetch("/api/config").then((res) => res.json()),
  fetch("/api/flags").then((res) => res.json()),
]);

All three are in flight before the first await. Total time is the slowest one. Promise.all keeps the order of the input array regardless of which finishes first.

Sequential awaits are correct when the second call genuinely needs the first result. If it doesn't, it belongs in the array.

all rejects on the first failure

// one bad response and you get nothing, even if the others succeeded
const results = await Promise.all(ids.map((id) => fetchUser(id)));

That's what you want for data a screen can't render without. When a partial result is still useful, use allSettled:

const settled = await Promise.allSettled(ids.map((id) => fetchUser(id)));

const users = [];

for (const result of settled) {
  if (result.status === "rejected") {
    log(result.reason);
    continue;
  }

  users.push(result.value);
}

allSettled never rejects. Every entry is { status: "fulfilled", value } or { status: "rejected", reason }, so the failures are data you handle rather than an exception that skips the rest.

race and any

// first to settle wins, including a rejection — the timeout pattern
const data = await Promise.race([
  fetchUser(id),
  rejectAfter(5000, new Error("Timed out")),
]);

// first to succeed wins; rejects only if all of them fail
const mirror = await Promise.any([fetchFrom(primary), fetchFrom(backup)]);

Neither cancels the losers — they keep running, and their results are simply ignored. Stopping the work needs an AbortController (lesson 6).
