Lazy Loading Components

React supports lazy loading components with React.lazy() and Suspense. The lazy() function returns a promise and will resolve when the component has been downloaded.

LazyWrapper protects against errors in the lazy component from tearing down the entire page by adding a Suspense and ErrorBoundary automatically. See the next two sections for more details on these.


    import { lazy } from "react";
    import { LazyWrapper } from "@path/to/LazyWrapper";

    const OfferBanner = lazy(() => import("@path/to/component/OfferBanner"));

    const MyPage = () => {
      
      // render logic 
      
      return (
        <LazyWrapper fallback={Skeleton}>
          <OfferBanner />
        </LazyWrapper>
      );
