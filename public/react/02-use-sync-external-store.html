useSyncExternalStore

useSyncExternalStore asks for two functions:

  • one to subscribe to changes
  • one to retrieve the current state of the store

function useSyncExternalStore<Snapshot>(
  
  // function to trigger a re-render when the store changes
  subscribe: (onStoreChange: () => void) => () => void,
  
  // function to get the current state of the store
  getSnapshot: () => Snapshot,

): Snapshot;

Note here, Snapshot is the state returned by the store. This is just a Javascript Object.

Usage

import { useSyncExternalStore } from "react";
import { store } from "./cart-store.js";

const CartBadge = () => {
  const cart = useSyncExternalStore(store.subscribe, store.getSnapshot);

  return <span>{cart.items.length}</span>;
};

React Component subscribes in the render function and gets the latest snapshot when the listener is fired by the store.

Implementation advice - Wrap it in a hook

Suggest you define outside the component rather than inline and give more descriptive names:

// cart-hooks.js
import { useSyncExternalStore } from "react";
import { store } from "./cart-store.js";

// returns the number of items in the cart
const getCount = (): number => {
  const snapshot = store.getSnapshot() as { items: CartItem[] };
  return snapshot.items.length;
}

export const useCartCount = (): number => {
  return useSyncExternalStore(store.subscribe, getCount);
};

If the store snapshot contains more data than you need, you can use the hook to only return what the component cares about.

React Components import useCartCount and never touch the store directly.
