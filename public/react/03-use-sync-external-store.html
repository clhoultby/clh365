useSyncExternalStore

With the store in place, the component drops its useState and useEffect entirely:

import { useSyncExternalStore } from "react";
import { subscribe, getSnapshot } from "./cart-store.js";

const CartBadge = () => {
  const cart = useSyncExternalStore(subscribe, getSnapshot);

  return <span>{cart.items.length}</span>;
};

React subscribes on mount, unsubscribes on unmount, and re-reads the snapshot whenever a listener fires. The part an effect can't replicate: React also re-reads the snapshot before committing, and restarts the render if the value moved while it was working. Every component reading this store in a given commit sees the same value.

The snapshot must be referentially stable

React calls getSnapshot during render and compares the result to the last one. If it returns a fresh object each time, the value never compares equal, and React re-renders forever:

// infinite loop — a new object on every call
useSyncExternalStore(subscribe, () => {
  return { count: getSnapshot().items.length };
});

// fine — a number, compared by value
useSyncExternalStore(subscribe, () => {
  return getSnapshot().items.length;
});

Select a primitive where you can. When a component genuinely needs a derived object, cache it in the store and return the cached reference until the underlying state changes.

Wrap it in a hook

Both arguments should be stable references, so define them outside the component rather than inline:

// cart-hooks.js
import { useSyncExternalStore } from "react";
import { subscribe, getSnapshot } from "./cart-store.js";

const getCount = () => getSnapshot().items.length;

export const useCartCount = () => {
  return useSyncExternalStore(subscribe, getCount);
};

Components import useCartCount and never touch the store directly. The store stays plain JavaScript that the other framework can own, and React's dependency on it is one hook in one file.

If the app server-renders, pass a third argument — getServerSnapshot — returning the value to use during SSR and hydration, since the client store doesn't exist on the server.
