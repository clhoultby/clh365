Suspense

Suspense is a used to wrap anything inside it that isn't ready yet. It relies on a Promise resolving to render the component or rejecting to show an error

This could be:

  • lazy() component that is still downloading
  • a component doing an API fetch
  • a component awaiting a subscription

Until the Promise resolves, React renders the fallback in its place until the wait is over:

Usage

Wrap the lazy component in a Suspense and provide a fallback UI, e.g. a spinner or skeleton, to show while the lazy component is loading. 

import { Suspense, lazy } from "react";

const OfferBanner = lazy(() => import("@path/to/component/OfferBanner"));

return (
  <Suspense fallback={<Skeleton />}>
    <OfferBanner />
  </Suspense>
);
